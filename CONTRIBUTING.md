# Contributing

1. Read `AGENTS.md` and the relevant design document first.
2. Open one focused issue or task per change.
3. Use a feature branch; do not commit secrets or active configuration URLs.
4. Add tests for parser, conversion, routing decisions and connection lifecycle changes.
5. Run available formatting, analysis and tests; report commands and results accurately.
6. Update `docs/ROADMAP_FA.md` only after the task's acceptance criteria are met.
7. For engine or platform changes, include target OS, architecture, engine version, build flags and license review notes.

Do not submit copied third-party code without recording its source and license.
