# Test assets

- نمونه‌ها باید Sanitized و مصنوعی یا با اجازه و حذف کامل اسرار باشند.
- fixtureها نباید به endpoint واقعی مشتری وصل شوند.
- برای هر protocol/parser تست معتبر، نامعتبر، malformed، مرزی و fuzz در نظر گرفته شود.
- هر تست اتصال باید دستگاه/OS/Engine version و profile fixture ID را ثبت کند.
