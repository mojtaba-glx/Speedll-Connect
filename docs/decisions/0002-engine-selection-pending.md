# ADR 0002 — انتخاب استراتژی تک‌موتوره برای MVP (موتور sing-box)

- Status: Accepted (MVP Single-Engine Strategy)
- Date: 2026-11-10

## تصمیم

1. برای نسخه MVP، تمرکز توسعه تنها بر روی یک هسته واحد یعنی **sing-box** خواهد بود.
2. هسته **Xray-core** تا زمان اثبات نیاز قطعی و اختصاصی در آینده، وارد وابستگی‌های اجرایی و باینری پروژه نمی‌شود تا از دو برابر شدن حجم برنامه، پیچیدگی لایه‌های عیب‌یابی و سربار نگهداری دو هسته جلوگیری شود.
3. قبل از هرگونه بسته‌بندی نهایی یا پیوند باینری sing-box، تعهدات مجوز (GPL-3.0-or-later) و نحوه ادغام آن از طریق لایه کاملاً ایزوله Native Adapter مستند و رعایت شود تا کدهای رابط کاربری و تجاری فلاتر دچار اثر ویروسی مجوز نشوند.

## پیامدها

- ساده‌سازی معماری Adapter و تست‌ها در فازهای P2 و P3.
- سبک ماندن حجم خروجی نصبی نرم‌افزار.
- امکان ارزیابی مجدد هسته ثانویه در فازهای بعدی صرفاً در صورت نیاز واقعی و گزارش سازگاری رسمی.
