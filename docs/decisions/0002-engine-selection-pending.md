# ADR 0002 — انتخاب موتور هنوز در انتظار POC است

- Status: Proposed / Pending
- Date: 2026-11-09

## گزینه‌ها

- sing-box به‌عنوان نامزد اصلی
- Xray-core به‌عنوان نامزد مکمل
- استفاده از یک Engine برای MVP و اضافه‌کردن Engine دوم فقط در صورت نیاز ثابت‌شده

## تصمیم فعلی

هیچ Engine تا پایان P1/P2 به‌عنوان وابستگی نهایی تثبیت نمی‌شود.

## معیار تصمیم

- سازگاری feature-level با نمونه‌های واقعی Sanitized
- پوشش سیستم‌عامل و API library
- پایداری lifecycle و کیفیت نگهداری
- عملکرد و مصرف منابع
- مجوز و هزینه رعایت الزامات توزیع
- اندازه binary و پیچیدگی build/release
