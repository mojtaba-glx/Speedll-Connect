# ADR 0001 — شکل اولیه محصول

- Status: Accepted (initial direction)
- Date: 2026-11-09

## تصمیم

Speedll Connect یک کلاینت مستقل با Flutter UI و هدف پنج سیستم‌عامل است. محصول عمومی رایگان خواهد بود و اتصال حساب/امکانات اختصاصی Speedll به‌صورت اختیاری ارائه می‌شود. UI، subscription pipeline، engine adapters و native VPN adapters از هم جدا می‌مانند.

## دلیل

این جداسازی UX ساده را از پیچیدگی‌های engine و تفاوت سیستم‌عامل‌ها مستقل نگه می‌دارد و امکان توسعه مرحله‌ای می‌دهد.

## پیامد

پشتیبانی پنج سیستم‌عامل به معنی یک کد واحد برای تمام جزئیات VPN نیست؛ adapter، build و تست مستقل هر پلتفرم الزامی است.
